# AutoClicker Pro

نسخه بازطراحی‌شده اتوکلیکر اندروید با تمرکز روی کنترل شناور، انتخاب مستقیم نقطه/ناحیه و پروفایل‌های جداگانه.

## امکانات
- انتخاب نقطه مستقیم از روی صفحه، بدون وارد کردن مختصات
- انتخاب یک ناحیه مستطیلی و کلیک تصادفی داخل همان ناحیه
- کنترل شناور خارج از برنامه: شروع/توقف و کم‌وزیاد کردن سرعت
- چهار پروفایل مستقل با ذخیره تنظیمات
- تنظیم فاصله کلیک از 50ms تا 60s
- تعداد کلیک محدود یا بی‌نهایت
- رابط سه‌تب با توضیح کوتاه برای هر بخش
- استفاده از Android AccessibilityService و Gesture API

## راه‌اندازی
1. برنامه را نصب کن.
2. از داخل برنامه، Accessibility را فعال کن.
3. از تب «نقاط» نقطه یا ناحیه را انتخاب کن.
4. از «تنظیمات» سرعت و تعداد کلیک را مشخص کن.
5. «کنترل شناور» را فعال کن و Start را بزن.

> این پروژه برای استفاده روی دستگاه خودت طراحی شده و کلیک‌ها را با API رسمی Accessibility اندروید انجام می‌دهد.
